# Raven — frontend

Next.js 16 / React 19 dashboard for Raven. See the [root README](../README.md) for the full project.

```bash
npm install
npm run dev   # http://localhost:3000 — click "Replay recorded analysis"
```

Set `NEXT_PUBLIC_API_URL` to point at the FastAPI backend (default `http://localhost:8001`).
